# Gughan S — Portfolio website

A responsive, minimal portfolio made with plain HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, responsive styles, and theme
- `script.js` — mobile navigation, photo fallback, current year, and contact form
- `assets/profile-photo.jpg` — add your own photo here (see below)

## Add your photo
1. Choose a clear portrait photo.
2. Copy it into the `assets` folder.
3. Name it exactly `profile-photo.jpg`.
4. Refresh `index.html` in your browser.

If the photo is not present yet, the page shows a simple initials placeholder.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required. The Google Fonts import is optional; system sans-serif fallbacks are included.

## Contact form
The form validates required fields and opens the visitor's default email app with a pre-filled message addressed to `gughan.sivasubramaniyam@gmail.com`. It does not send mail directly or store submissions. A server-side endpoint or form service would be needed for direct website submissions.

## Edit projects
The Projects section currently contains an explicit placeholder rather than made-up projects. Edit the marked area in `index.html` when you have real projects to show.

## Personal details
The supplied display name, course, college, graduation year, skills, GitHub, LinkedIn, and email are included in the page. Check the education start year if you want to show a different date range.
