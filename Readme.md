## 🚀 Run Locally

1. Download or clone this repository.
2. Keep the HTML, CSS, JavaScript, and profile image files together.
3. Open `index.html` in your browser.

## 🌍 Deploy with GitHub Pages

1. Create a public repository named `Gughan1759.github.io`.
2. Upload your website files.
3. Go to **Settings → Pages**.
4. Select the `main` branch and the root folder.
5. Save and wait for deployment.

Website URL: https://Gughan1759.github.io/

*The website link will work after GitHub Pages deployment succeeds.*
